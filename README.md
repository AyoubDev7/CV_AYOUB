# CV web — Ayoub Dfil

Projet SAÉ 1.04, BUT Réseaux et Télécommunications, IUT de Colmar, 2026–2027.

Site personnel de quatre pages, entièrement en HTML et CSS, sans JavaScript ni framework.

## Consulter le site

Télécharger le dépôt, puis ouvrir `index.html` dans un navigateur. Garder les quatre pages, `style.css` et `photo.png` dans le même dossier.

## Organisation

- `index.html` : profil, parcours synthétique, compétences et résumé anglais.
- `formations.html` : études et présentation du projet.
- `diplomes.html` : diplômes obtenus.
- `experiences.html` : ALDI, Poulaillon et service civique.
- `style.css` : feuille de style unique, commune aux quatre pages.
- `photo.png` : portrait personnel.
- [PROJET.md](PROJET.md) : description, choix et fonctionnement du projet.
- [VERIFICATION.md](VERIFICATION.md) : correspondance avec les critères et contrôles.

## Conception

Palette ivoire, encre et cuivre ; colonnes ouvertes et repères numérotés. HTML sémantique, liens avec ancres, Flexbox et Grid, adaptation mobile, navigation au clavier et style d’impression.

La photographie et les informations personnelles appartiennent à Ayoub Dfil.
