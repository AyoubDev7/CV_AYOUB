# CV web — Ayoub Dfil
Projet SAÉ 1.04, BUT Réseaux et Télécommunications, IUT de Colmar, 2026–2027.
Site personnel de quatre pages, entièrement en HTML et CSS.

## Organisation

- `index.html` : profil, parcours synthétique, compétences et résumé anglais.
- `formations.html` : études et présentation du projet.
- `diplomes.html` : diplômes obtenus.
- `experiences.html` : ALDI, Poulaillon et service civique.
- `style.css` : feuille de style unique, commune aux quatre pages.
- `photo.png` : portrait personnel.


## Le projet

Ce CV présente mon parcours en BUT Réseaux et Télécommunications à l’IUT de Colmar, mes bases techniques et les compétences développées en entreprise et dans le bénévolat. Mon objectif est d’évoluer dans les réseaux, les systèmes et la cybersécurité.

Réalisé pour la SAÉ 1.04, le site utilise HTML pour structurer le contenu et une feuille CSS commune pour la présentation. Les quatre pages sont reliées par des ancres ; Flexbox, Grid et les règles d’adaptation permettent une lecture sur ordinateur et mobile. Le site fonctionne sans JavaScript.

Pour le consulter en local, télécharger le dépôt et ouvrir `index.html`, en conservant les fichiers dans le même dossier.
